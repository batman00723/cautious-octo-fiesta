  How easy is it to set up?                                                                                                                                                            
  It only takes two steps.                                                                                                                                                             
                                                                                                                                                                                       
  1. We run one single terminal command: python manage.py createcachetable my_cache_table. (This tells Django to automatically build the hidden tracking table in PostgreSQL).         
  2. We add this block to your settings.py:                                                                                                                                            
                                                                                                                                                                                       
    CACHES = {                                                                                                                                                                         
        'default': {                                                                                                                                                                   
            'BACKEND': 'django.core.cache.backends.db.DatabaseCache',                                                                                                                  
            'LOCATION': 'my_cache_table',                                                                                                                                              
        }                                                                                                                                                                              
    }                                                                                                                                                                                  
                                                                                                                                                                                       
  That's it! Now the @throttle decorator will permanently save the IPs into PostgreSQL. For a startup MVP, this is an incredibly smart, low-maintenance way to handle it!  


    We would add this block to the bottom of your settings.py:                                                                                                                           
                                                                                                                                                                                       
    NINJA_EXTRA = {                                                                                                                                                                    
        # 1. Tell Ninja which tracking classes to use                                                                                                                                  
        'THROTTLE_CLASSES': [                                                                                                                                                          
            'ninja_extra.throttling.AnonRateThrottle',                                                                                                                                 
            'ninja_extra.throttling.UserRateThrottle'                                                                                                                                  
        ],                                                                                                                                                                             
                                                                                                                                                                                       
        # 2. Set the global speed limits!                                                                                                                                              
        'THROTTLE_RATES': {                                                                                                                                                            
            'anon': '30/m',   # Anonymous IPs can only hit APIs 30 times a minute                                                                                                      
            'user': '100/m',  # Logged-in users get a higher limit                                                                                                                     
        }                                                                                                                                                                              
    }                                                                                                                                                                                  
                                                                                                                                                                                       
  By defining this in settings.py, you create a global rulebook. Then, any time you put @throttle on one of your endpoints in search_controller.py, it automatically looks at this     
  rulebook, sees the person isn't logged in, and applies the strict 30/m Anonymous rule.
